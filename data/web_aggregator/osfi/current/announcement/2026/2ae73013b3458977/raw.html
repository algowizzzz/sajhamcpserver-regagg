Filing corporate returns

Federally regulated financial institutions must file regulatory corporate returns at various times or after specific events. You can find the list of required regulatory corporate returns in the following tables.

All regulatory corporate returns need to be filed through the Regulatory Reporting System. See more information on how to file and submit a return.

There are penalties for filing late returns, or returns with errors. See more information on the Late and Erroneous Filing Penalties Framework.
