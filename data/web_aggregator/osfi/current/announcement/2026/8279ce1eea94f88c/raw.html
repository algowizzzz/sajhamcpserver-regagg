Context

This document lists the validation rules for the securities holdings return.  This list of rules is the same as what is posted in the validation rules section of the securities holdings return; however, this is a more detailed format that may be preferable to some users.  For questions please contact DDS-FIS@bank-banque-canada.ca.

Data Format Rules

Variable Validation Rules
ISIN Values must be an allowable ISIN format
CUSIP Values must be an allowable CUSIP format
LEI of Security Issuer Values must be an allowable LEI format
Security classification if no ISIN or CUSIP Values must be 1 to 6 or blank
If an ISIN or CUSIP is reported the value must be blank
If an ISIN or CUSIP is not reported the value must not be blank
Indicator if security is held by a CIRO integrated broker dealer subsidiary Values must be 1 to 9 or blank
Only BMO may report 1, only CIBC may report 2 & 3, only Laurentian may report 4, only NBC may report 5, only RBC may report 6, only BNS may report 7, only TD may report 8 & 9.
Indicator if collateral position is vis-à-vis a prime broker client Values must be 1 or blank
Values must be blank for H4 cells from: Part A Section 1 & 2, and Part B
Sections 1 through 4.
H4 cell or memo item number Values must be allowable format (e.g. "a5c31" or "memo1")
H4 cell values must be one of the H4 cells selected for reporting and memo items must be requested by BoC, see instruction document for details.

Data Validation Rules with H4 Return

General Validation Rule Between Securities Holdings Return and H4

The sum of security market values for an H4 cell must be between 98% & 102% of that H4 cell's reported value, unless that H4 cell's value is < 5 mill.***

*** Note: in some cases an H4 cell's reported value can include a cash component, these cash components are excluded from the validation. E.g. when the Securities Holdings Return is reconciled to H4 cell b77c31 for total liquid asset pledging to DTC/DTCC, the reconciliation is vis-a-vis securities reported in b77c31 and not cash deposits reported in b77c31.
