# Concept Proposal - Extension of Testing: 12-401 - National Application System

Concept Proposal

## July 3, 1998

**NATIONAL APPLICATION SYSTEM  
CONCEPT PROPOSAL 12-401  
Extension of Testing**

In January, 1998 the Canadian Securities Administrators (the "CSA") published a request for comments with respect to the National Application System which included a concept proposal for the system. At the same time the CSA indicated that it would immediately commence testing of the system based on the concept proposal.  
  
  
The comments period ended on June 1, 1998 but the CSA has extended the testing of the system until further notice.  
  
  
Law firms participating in testing the system may continue to use the system by following the procedures set out in the concept proposal.  
  
  
Testing of the system was also extended to all types of applications for exemptive relief on June 15, 1998. As of that date law firms participating in testing the system may make any application for relief under the system except those applications where the granting of a registration certificate or the issuing of a prospectus receipt has traditionally granted the relief.  
  
  
The CSA National Application System Committee will review the comments received and the experience gained from testing to date and report to the CSA. It is expected a policy for the system will be prepared and published for comments in September, 1998.
