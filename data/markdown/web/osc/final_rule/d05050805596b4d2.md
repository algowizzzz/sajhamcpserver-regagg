# Revocation: OSC Rule - 55-501 - Insider Report Form

OSC Rule

## February 21, 2003

[Download document](/sites/default/files/pdfs/irps/rule_20030221_55-501_revocation.pdf "Open document in new window")

**RULE 55-501 INSIDER REPORT - REVOCATION DATE CLARIFIED**

Please note that, effective November 13, 2001, Rule 55-501 *Insider Report* was revoked. This rule was replaced by Form 55-102F6 for insiders filing reports in paper format.
