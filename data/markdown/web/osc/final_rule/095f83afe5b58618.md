# SEDAR System Updates: OSC Staff Notice - 13-701 - SEDAR Filings and Year 2000 Contingency Plans

OSC Notice

## January 10, 2001

January 4, 2001

**SEDAR System Updates**

National Instrument 44-101 - Short Form Prospectus Distributions, National Instrument 44-103 -PREP, National Instrument 44-102 - Shelf Distributions (collectively the "National Instruments") and Rule 41-501 - General Prospectus Requirements (the "Rule") came into effect December 31, 2000.   
  
Various new filing types and document types to permit the filing of documents in accordance with the new National Instruments and the Rule will be added to the SEDAR system in a code update on January 29, 2001. A subscriber update will be released later in January which discusses the changes in detail.   
  
Prior to the code update, filers should continue to file documents under the old filing types and document types.
