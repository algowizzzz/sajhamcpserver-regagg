# Section 314(a)

**IMPORTANT INFORMATION!**

This is to notify Legacy SISS users that the Legacy SISS URL has been changed to <https://fiportal.fincen.gov>. Users are advised to update their bookmarks and begin using the new FI Portal URL. The previous SISS URLs (<https://fincen.gov/314a> and <https://fincen.gov/314b>) will no longer be valid after 5/23/2024.
