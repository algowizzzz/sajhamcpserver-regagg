# Media Releases

IOSCO is pleased to support media outlets in their coverage of issues and developments impacting financial regulation worldwide.

Please get in touch if you would like to speak to IOSCO about any of [the work it is currently involved in](/library/pubdocs/pdf/IOSCOPD813.pdf).  
For media inquiries, please contact:

Emilie Bernard

Communications Manager

Email: [e.bernard@iosco.org](mailto:e.bernard@iosco.org)

Email: [e.bernard@iosco.org](mailto:e.bernard@iosco.org)

**If you require a press release prior to 2021, please contact [Press@iosco.org](mailto:Press@iosco.org). We aim to respond within 24 hours.**
