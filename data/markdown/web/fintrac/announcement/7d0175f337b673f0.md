# Paper reporting forms : Methods to report to FINTRAC

**From:** [Financial Transactions and Reports Analysis Centre of Canada](/intro-eng) (FINTRAC)

Access FINTRAC's paper reporting forms for all report types.

## Requirements to report electronically

Reporting entities must submit all [reports electronically](/reporting-declaration/electron-eng) if they have the technical capability to do so, except for the Terrorist Property Report, which can only be submitted using the paper form.
