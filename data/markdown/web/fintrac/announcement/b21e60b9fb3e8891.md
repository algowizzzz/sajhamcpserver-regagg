# Formulaires de déclaration sur support papier : Méthodes de déclaration à CANAFE

**Du** : [Centre d'analyse des déclarations et opérations financières du Canada](/intro-eng) (CANAFE)

Accédez aux formulaires de déclaration sur support papier de CANAFE pour tous les types de déclaration.

## Déclaration par voie électronique

Les entités déclarantes doivent transmettre toutes les déclarations [par voie électronique](/reporting-declaration/electron-fra) si elles ont une connexion Internet, sauf les déclarations de biens appartenant à un groupe terroriste qui doivent être transmises avec le formulaire sur support papier.
