## Objet

Les institutions de dépôts (ID) peuvent soumettre leurs données sur le LCR et le LCR selon l’outil de surveillance par devise significative[Note de bas de page 1](#fnb1) (s’il y a lieu) par l’intermédiaire du Système de déclaration réglementaire :

1. soit en saisissant des valeurs directement sur le formulaire Web du SDR;
2. soit en téléversant un fichier de données en format XML.

Le présent document offre les réponses du BSIF à une série de questions courantes sur les aspects techniques des relevés soumis en format XML.

## Questions d’ordre technique

Q1. Quel est le code officiel du relevé LCR?

Le code officiel de deux lettres est LA.

Q2. Où se trouvent les spécifications techniques du relevé LCR?

Un fichier de définition de schéma XML (XSD) indique les éléments des fichiers XML acceptables. Le fichier XSD du relevé LCR peut être téléchargé dans le portail SDR. La figure 1 ci-après en indique l’emplacement exact en rouge. Le portail contient deux fichiers utiles : « LA Schema Definition.xsd » et « LA – XML Sample Data.xml ».

Figure 1

![FAQ de nature technique Figure 1](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_1.png)

Q3. Est-il possible de saisir directement les données sur le LCR plutôt que de soumettre un fichier XML?

Oui, les ID peuvent saisir les données sur le LCR directement sur un formulaire Web.

Q4. Quelle est la valeur « FirmID » de mon ID?

Cet élément facultatif ne doit pas être inclus dans le fichier XML généré et soumis par une ID.  S’il y a lieu, veuillez supprimer l’élément FirmID du dossier XML (voir la figure 2). Ce problème technique sera réglé lors d’une prochaine révision du Système de déclaration réglementaire.

Figure 2

![FAQ de nature technique Figure 2](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_2.png)

Q5. Quel nom faut-il donner à un fichier XML?

Il n’y a aucune restriction sur l’appellation des fichiers.

Q6. Faut-il établir un fichier XML distinct pour chaque devise?

Non. Les données sur toutes les devises déclarées doivent figurer dans un seul fichier XML. L’exemple donné à la figure 3 illustre un fichier XML dans lequel trois devises sont déclarées. Chacune doit être située sous l’identification « LCR\_x0020\_Repeat\_x0020\_Group », comme l’indique l’encadré bleu.

Figure 3

![FAQ de nature technique Figure 3](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_3.png)

Q7. Le BSIF fournira-t-il un milieu d’essais?

Non. Toutefois, les ID ont accès au relevé LCR dans le SDR depuis le 15 janvier 2015 pour pouvoir en faire l’essai. Elles peuvent soumettre des fichiers expérimentaux à n’importe quel moment, et elles seront automatiquement autorisées à présenter par la suite des relevés corrigés, et ce, jusqu’à la date limite du 14 février 2015 prévue pour la période de déclaration de janvier 2015.

## Renseignements complémentaires

N1. Pour le relevé de janvier 2015 seulement, les ID qui sont des adhérents verront apparaître des erreurs de validation lorsque l’APD 99039 sera fixé à zéro, même si cette valeur est exacte. La figure 4 illustre cette situation.

Figure 4

![FAQ de nature technique Figure 4](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_4.png)

Le BSIF ne tiendra pas compte de l’erreur causée par la règle de validation D99039A, et le problème sera réglé en prévision des relevés futurs. Toutefois, toutes les autres règles de validation doivent être observées.

N2. Parmi les nombreux outils à utiliser pour produire des fichiers XML, notons qu’Excel offre la possibilité d’importer un fichier XSD, d’en schématiser chaque élément, puis d’exporter le fichier en format XML. Les étapes du processus sont les suivantes (dans Excel 2010) :

1. À l’onglet **Developer**, sélectionnez **Source** dans le groupe d’icônes **XML**.
   1. ![FAQ de nature technique Figure 5](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_5.png)
2. Dans le volet **XML Source**, cliquez sur le bouton **XML Maps….**
   1. ![FAQ de nature technique Figure 6](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_6.png)
3. Dans la fenêtre **XML Maps,** cliquez sur **Add** et sélectionnez un fichier XSD. Cliquez sur **OK**. Le fichier XSD qui correspond au relevé LCR s’intitule « LA Schema Definition.xsd » et il est situé dans le portail SDR, comme l’explique la réponse à la question 2.
   1. ![FAQ de nature technique Figure 7](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_7.png)
4. Le volet **XML Source** énumère tous les éléments schématiques d’une hiérarchie. Il est possible de schématiser chaque élément ou un groupe d’éléments en utilisant la fonction glisser-déplacer. À noter qu’Excel (ou certaines versions du logiciel) n’accepte pas la présence d’éléments en double dans un même tableau, ce qui veut dire qu’il est nécessaire de créer un fichier Excel distinct pour chaque devise. Dans chaque fichier, l’élément « LCR Repeat Group » (ou n’importe quel de ses éléments enfant) peut être placé sur une feuille de calcul au moyen de la fonction glisser-déplacer pour créer un tableau horizontal comportant tous les éléments enfant.
   1. ![FAQ de nature technique Figure 8](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_8.png)
5. Lorsque les éléments schématiques ont été rattachés à des données (ou les valeurs saisies), cliquez sur **Export** dans le groupe d’icônes XML. Si cette méthode est suivie dans Excel, un fichier XML distinct sera créé pour chaque devise. Pour téléverser tous les fichiers XML dans le SDR, il faut les intégrer à un seul fichier, comme l’explique la réponse à la question no 6.
   1. ![FAQ de nature technique Figure 9](/sites/default/files/import-media/data_and_forms/deposit-taking-institutions/2015-04/fr/lcr_faq_9.png)
6. Les éléments au contenu numérique ne peuvent être laissés en blanc, sinon une erreur se produira au moment du téléversement du fichier dans le SDR. Les éléments vides doivent être supprimés du fichier XML. Fait à noter, zéro est une valeur valide.
