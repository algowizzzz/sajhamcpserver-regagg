# File and submit a return

Federally regulated financial institutions and pension plans need to file regular returns with us. We provide instructions on how to meet these requirements to file corporate and financial returns, for deposit-taking institutions, insurance companies and pension plans.

## On this page

## File a return for a financial institution

Use the reporting forms and instructions to help you file your returns correctly and within a designated reporting period.

* [Filing corporate returns](/en/data-forms/reporting-returns/filing-corporate-returns "Filing corporate returns")
* [Filing financial returns](/en/data-forms/reporting-returns/filing-financial-returns "Filing financial returns")

[Database of financial reporting forms and instructions](/en/data-forms/reporting-returns/filing-financial-returns/financial-reporting-instructions "Financial reporting instructions")

### Fines for late and erroneous submission

File your reports correctly and on time. Some returns and related documents are subject to [penalties for late and erroneous filing](/en/data-forms/reporting-returns/file-submit-return/administrative-procedures-late-erroneous-filing-penalty-lefp-framework "Administrative Procedures for the Late and Erroneous Filing Penalty (LEFP) Framework"). Federally regulated pension plans are not currently subject to these penalties.

## File a pension plan return

Refer to the reporting instructions for filling processes and due dates.

* [Process for defined benefits pension plan annual returns](/en/supervision/pensions/administering-pension-plans/guidance-topic/filing-process-defined-benefit-pension-plan-returns "Filing Process for Defined Benefit Pension Plan Returns")
* [Process for defined contributions pension plan annual returns](/en/supervision/pensions/administering-pension-plans/guidance-topic/annual-filing-process-defined-contribution-pension-plan-returns "Annual Filing Process for Defined Contribution Pension Plan Returns")
* [Process for pooled registered pension plan annual returns](/en/supervision/pensions/administering-pension-plans/guidance-topic/annual-filing-process-pooled-registered-pension-plan-returns "Annual Filing Process for Pooled Registered Pension Plan Returns")
* [Process for pension plan amendments, applications and approvals](/en/supervision/pensions/administering-pension-plans/amendments-applications-approvals "Amendments, Applications and Approvals")

### Important: registering a pension plan

To register a pension plan, submit your registration application by email to [Approvals-Approbations@osfi-bsif.gc.ca](mailto:Approvals-Approbations@osfi-bsif.gc.ca). Include all supporting documents with your application.

Use the Regulatory Reporting System to submit corporate and financial returns.
