## Instructions générales

La phase 3 de l’appel de données sur les prêts aux entreprises (relevé BSIF 988) élargit la portée de l’appel de données pour inclure les prêts aux grands comptes (notamment les catégories d’actifs suivantes : prêts aux grandes entreprises, prêts aux emprunteurs souverains, prêts aux banques et prêts commerciaux).

Pour la phase 3, le premier relevé de l’appel de données sur les prêts aux entreprises (BSIF 988) doit être transmis au plus tard le 25 février 2025. Les données à déclarer dans ce relevé sont les données en date du 31 janvier 2025.

Par la suite, le relevé devra être transmis au BSIF au plus tard le 25 de chaque mois. Si la date de production tombe une fin de semaine ou un jour férié, le relevé doit être transmis le jour ouvrable suivant.

Les données soumises doivent respecter le modèle de présentation standard qui est imposé dans le document « BSIF 988 – Prêts aux entreprises Phase 3 – Gabarit de présentation des données ».

### Portée révisée de l’appel de données

#### Régions

Toutes les régions (États-Unis, Canada et Autres pays)

#### Catégories d’actifs

* Prêts immobiliers commerciaux
* Prêts aux grandes entreprises, prêts aux emprunteurs souverains, prêts aux banques, prêts commerciaux

### Modèle de présentation des données

Les données produites doivent :

* figurer dans un fichier texte brut dans lequel les valeurs sont séparées par une barre verticale;
* inclure tous les éléments de données indiqués dans le gabarit de présentation des données de l’appel de données sur les prêts aux entreprises (BSIF 988), dans l’ordre où ils figurent dans le gabarit;
* être nulles[Note de bas de page 1](#fn1) lorsqu’un élément de données n’est pas connu ou sans objet, sauf indication contraire;
* correspondre à la valeur actuelle de l’élément de données en question, sauf indication contraire.

Les données produites ne doivent **pas** :

* contenir de barre verticale dans un champ;
* contenir de retour chariot dans un champ;
* être chiffrées.

### Transmission des données

Les données doivent être transmises par l’intermédiaire du Système de déclaration réglementaire (SDR) en utilisant le code de relevé **BSIF 988**.

On trouvera les instructions de dépôt sur le site Web du BSIF, sous [Système de déclaration réglementaire (SDR) – Guide d’utilisation – Gestion des relevés financiers (PDF)](/sites/default/files/documents/rrs_mcr_FR.pdf "rrs_mcr_FR.pdf").

Il est possible de téléverser quatre fichiers par relevé. Les fichiers doivent être ajoutés aux espaces de téléchargement prévus à cet effet, dans l’ordre suivant :

* 01 – Emprunteur
* 02 – Facilité
* 03 – Sûreté
* 04 – Projet d’aménagement

Un relevé ne sera considéré comme complet que si tous les fichiers ont été ajoutés. S’il n’y a aucune donnée pertinente à déclarer dans un fichier individuel, il faut tout de même inclure le fichier en question; conserver la présentation et les en-têtes de colonnes, mais ne pas inclure de rangées de données.

### Description détaillée du fichier

Le relevé de l’appel de données sur les prêts aux entreprises est divisé en quatre (4) fichiers distincts, lesquels sont décrits dans le gabarit de présentation des données de la phase 3 et doivent être transmis chaque mois pour répondre à l’appel de données.

01 – Emprunteur
:   Déclarer tous les emprunteurs visés par la phase 3 à la fin de chaque période de déclaration

02 – Facilité
:   Déclarer toutes les facilités visées associées à un emprunteur inclus dans le fichier 01 – Emprunteur.

    * Le Numéro d’emprunteur (202) de chaque facilité doit correspondre au Numéro d’emprunteur (101) unique indiqué dans le fichier 01 – Emprunteur.
    * Le Numéro d’identification du projet (203) de chaque facilité non vide doit correspondre au Numéro d’identification du projet (401) unique indiqué dans le fichier 04 – Projet d’aménagement.

03 – Sûreté
:   Déclarer toutes les sûretés associées à chaque facilité incluse dans le fichier 02 – Facilité. Chaque sûreté individuelle doit être déclarée sur une rangée distincte (autrement dit, ne pas déclarer plusieurs sûretés dans un même enregistrement). Indiquer quelle est la sûreté principale unique de chaque facilité dans le champ Indicateur de sûreté principale (316).

    * Le Numéro de facilité (302) de chaque sûreté doit correspondre au Numéro de facilité (201) unique indiqué dans le fichier 02 – Facilité.

04 – Projet d’aménagement
:   Indiquer des précisions sur le projet d’aménagement ou de construction associé à chaque facilité indiquée dans le fichier 02 – Facilité, s’il y a lieu (crédit immobilier commercial seulement).

### Qualité des données

Les institutions financières (IF) doivent s’assurer que les données produites sont conformes aux définitions et aux modèles de présentation imposés. Bien que les définitions diffèrent d’un relevé réglementaire à l’autre, chaque IF doit s’assurer que les totaux de l’appel de données correspondent raisonnablement bien aux totaux du portefeuille indiqués dans d’autres relevés réglementaires.

### Rapports d’anomalies quant à la qualité des données

Un système automatisé traite les données présentées par les IF pour confirmer le respect des spécifications du gabarit et repérer d’éventuelles anomalies. Si le système détecte une anomalie dans un relevé, nous envoyons un rapport sur la qualité des données à l’IF qui précise quelle est l’anomalie, et nous demandons une explication ou la mise en place d’un plan d’action.

Selon la gravité de certaines anomalies, il est possible que nous demandions à l’IF de corriger la situation en présentant une nouvelle version du relevé. Dans un tel cas, quelle que soit la période de déclaration, il faut utiliser la plus récente version du gabarit pour produire la nouvelle version du relevé et inclure tous les fichiers.

Dans tous les cas, nous demandons à l’IF de répondre au rapport sur la qualité des données par courriel à l’adresse [nonretail.support-soutien.pretsauxenterprises@osfi-bsif.gc.ca](mailto:nonretail.support-soutien.pretsauxenterprises@osfi-bsif.gc.ca) afin que le système de contrôle de la qualité des données puisse traiter les commentaires reçus, le cas échéant.

Prière d’envoyer toute question sur cet appel de données à l’adresse suivante : [nonretail.support-soutien.pretsauxentreprises@osfi-bsif.gc.ca](mailto:nonretail.support-soutien.pretsauxentreprises@osfi-bsif.gc.ca).
