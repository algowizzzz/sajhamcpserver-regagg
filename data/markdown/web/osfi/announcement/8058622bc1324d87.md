# Guides d’intervention

Le processus d’intervention nous permet de cerner les situations préoccupantes et d’intervenir rapidement pour prévenir les pertes, ou les réduire au minimum. Lors d’interventions, les évaluations tiennent compte des particularités de l’institution :

* nature
* portée
* complexité
* profil de risque

Les guides d’intervention sont adaptés en fonction du secteur. Ils ont tous pour objectif de faire connaître le cadre d’intervention du BSIF et d’en accroître la transparence.
