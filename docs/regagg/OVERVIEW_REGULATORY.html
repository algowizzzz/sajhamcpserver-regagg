Change tracking — the audit trail

  • 506 archived versions — when a rule page changes, the prior text is archived first, then diffed. Nothing is ever overwritten.
  • Federal Register churn captured daily — 500 of the 506 archived changes come from the US daily rule flow, each with publication date and document number.
  • Line-by-line diffs in the dashboard — select any document version pair and see exactly what changed and when.
  • Supersede detection — reference grammars (B-13, CAR Ch.4, SR letters, NI 31-103, APS 220…) link revisions to the rules they replace.

Source governance

  • No source trusted until verified — every feed/sitemap passes a live verification gate before its regulator is collected; 29/30 currently green.
  • Bot-blocks are never evaded — AMF Québec blocks automated access (403); it is escalated through official channels, not worked around. The Federal Register moved to its sanctioned API text endpoint.
  • Polite by design — descriptive user-agent, per-domain rate limits, daily caps on giant sites.
  • Stateless & config-driven — regulator #31 is a YAML file, not code.
