The intelligence components — and how much AI each one actually needs

Watchlists

Counterparty names, rule families (CAR Ch.4, B-13, FRTB), sectors, jurisdictions — per analyst or per desk. Matching incoming documents against them is string/topic matching on data we already classify.

AI required: none
Trend signals

Corroboration strength (same event, N wires, M hours) · topic velocity (CRE mentions 4× trailing average) · regulator activity anomalies (OSFI 3× normal on liquidity). All computed from counts we already store.

AI required: none
Morning Brief agent

Scheduled 6am run: narrates the delta the deterministic layer flagged — new Critical rules, watchlist hits, velocity spikes. Written back as a corpus document with citations, rendered on My Desk.

AI: synthesis only — selection is deterministic
Impact Memo agent

Fires when a watched rule versions. Input: the line diff + both versions. Output: what changed substantively, deadlines extracted, affected topics — attached beside the diff it cites.

AI: synthesis only — the diff is computed, not imagined

The governance contract — why this passes model risk review

  • No citation, no claim. Every sentence an agent writes points at doc_id + version + lines. The corpus is versioned precisely so this is enforceable.
  • Deterministic decides, AI narrates. Materiality, watchlists and diffs choose what's worth looking at; the LLM only synthesizes over retrieved spans. It never discovers.
  • Advisory, never actioning. No agent touches a limit or a position. Output is a draft with sources; a human dispositions it — and that disposition is logged.
  • One truth. The 6am brief is a stored document, not a per-user generation. Two analysts can never see two different versions of what mattered.
