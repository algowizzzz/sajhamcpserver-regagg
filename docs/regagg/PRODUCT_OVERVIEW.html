Built for a credit analyst

  • Credit events surface first. Stories rank by obligor-risk impact: creditor protection, downgrades and defaults outrank “stocks rally” — today’s #1 was a borrower filing for creditor protection.
  • Every score is explainable. “final_rule ×1.4 (major operating) = 56; aml_cft +12; new +10” — defensible in model governance and audit.
  • Rule changes are diffable. 506 archived versions: see exactly what OSFI or the Fed changed, line by line, with dates.
  • Full audit trail. Every document carries its source URL, fetch date, version history and provenance — nothing is fabricated, ever.

How it works — stateless, config-driven, one YAML per source

1 · DETECTWatch 55 sources dailysitemaps, RSS, APIs — new & changed pages only
2 · FETCHCapture & normalizeHTML + policy PDFs → clean markdown
3 · VERSIONAppend-only archive7,078 versions; changes diffed, never overwritten
4 · SCORERank by materialitydeterministic credit-risk lens, banded Critical→Low
5 · SERVEDashboard + 12 MCP toolssearch, browse, diff, whats-new — agent-ready
